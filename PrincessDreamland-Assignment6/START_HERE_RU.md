# Princess Dreamland — Assignment 6

## Как открыть готовый проект
1. Распакуй PrincessDreamland-Assignment6.zip через «Извлечь всё».
2. В VS Code выбери File → Open Folder и папку PrincessDreamland-Assignment6.
3. В этой папке находятся index.html, team.html, contact.html, style.css, script.js, facts.json, princesses.json.
4. Если ты используешь готовую папку, ничего дополнительно вставлять не нужно.
5. Для переноса в старую папку скопируй из новой папки пять файлов: index.html, team.html, contact.html, style.css, script.js. Подтверди замену. facts.json и princesses.json сохрани: они нужны старым функциям.
6. Если переносишь вручную: открывай ОДНОИМЁННЫЙ файл в готовой папке, Ctrl+A → Ctrl+C; затем тот же файл в старой папке, Ctrl+A → Ctrl+V → Ctrl+S. Не вставляй HTML в JavaScript.
7. Старые assignment6.html, assignment6.css, assignment6.js из переписки не подключай: в этом варианте их нет.

## Запуск
Открой папку через Live Server в VS Code, если расширение уже установлено: правой кнопкой по index.html → Open with Live Server.
Либо используй GitHub Pages. Двойной щелчок по index.html не подходит для проверки fetch: он может заблокировать загрузку JSON.

## Что добавлено и как проверить
Task 0: F12 → Console. Есть «jQuery is ready!».
Task 1: Начни вводить mul в прежнее поле поиска. Остаётся Mulan. Фильтр категории тоже работает.
Task 2: Под полем появляются предложения. Нажми Mulan — поле заполнится.
Task 3: Введи a — все совпадения в названиях и описаниях карточек подсвечиваются. Очисти поиск — подсветка исчезнет. Это область поиска по карточкам, а не по меню сайта.
Task 4: Прокручивай страницу: вверху заполняется цветная полоса.
Task 5: Прокрути до Our Little World. Значения постепенно изменятся с 0 до 3 и 2. Для повторной демонстрации обнови страницу.
Task 6: Внизу главной страницы заполни Newsletter валидным именем и email, нажми Subscribe. На 2 секунды появятся spinner и Please wait…, кнопка будет отключена, затем восстановится. Это учебная имитация, без реальной подписки.
Task 7: После подписки появляется временное уведомление и затем исчезает.
Task 8: Нажми New Magic Fact, потом Copy Fact. Появляются ✓ Copied и Copied to clipboard!. Вставь результат в Блокнот через Ctrl+V. Проверяй на HTTPS GitHub Pages или localhost; при запрете браузера показана ошибка.
Task 9: F12 → Network → Img → обнови страницу, оставаясь наверху. Фотографии карточек запрашиваются, когда карточки появляются на экране. Если карточка уже видна, её фото загружается сразу — это правильно. При фильтре и Load More применяется та же проверка. Остальные статические изображения используют loading="lazy".

## Методы для защиты
$(document).ready() — запуск после готовности HTML.
.on() — обработка события.
.val() — значение поля.
.text() — текст элемента.
.append() — добавление элемента.
.prop("hidden", ...) — показать или скрыть карточку.
.prop("disabled", ...) — выключить или включить кнопку.
.css() — изменить ширину полосы.
.fadeIn(), .fadeOut() — плавно показать и скрыть уведомление.
.attr() — прочитать или записать атрибут.
setTimeout() — выполнить один раз позже.
setInterval(), clearInterval() — повторять действие и остановить повторение.
scrollTop(), height(), offset() — положение прокрутки и элементов; нужны для Tasks 4 и 9 и прямо связаны с подсказками задания.
navigator.clipboard.writeText() — браузерный API для обязательного Task 8. Его нет на слайде jQuery; одной jQuery недостаточно для записи в системный буфер. .then() обрабатывает успешное копирование и ошибку.
Подсветка: indexOf находит совпадение, slice делит текст, цикл повторяет поиск. <mark> выделяет совпадение. createTextNode сохраняет пользовательский текст как текст, чтобы специальные символы не ломали HTML.

На скриншоте Task 0 должны быть подключение jQuery, ready и сообщение консоли. Для Task 9 покажи код и Network с отложенными запросами.
